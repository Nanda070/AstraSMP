Высокотехнологичное бэкенд-ядро для сервера **ChetCraft**, написанное на Java под актуальный стек **Minecraft 1.21 (Paper API)**. Плагин полностью заменяет необходимость в тяжелых клиентских модах (типа Applied Energistics 2 / IndustrialCraft 2), реализуя сложные механики цифрового хранения данных, кастомных NBT-валидаций и хардкорного PvP-баланса исключительно на стороне сервера.

## 🛠 Ключевой функционал & Архитектура

### 1. Цифровые МЕ-Сети (ME Storage Infrastructure)
Полная серверная имплементация систем цифрового хранения ресурсов:
* **МЕ-Контроллер:** Энергетическое ядро сети. Имеет ограниченный радиус действия (16 блоков), координирует работу подключенных компонентов.
* **МЕ-Дисковод:** Физическая консоль, вмещающая до 10 ячеек хранения. Реализована система рисков — при уничтожении блока дисковода ячейки выпадают в мир.
* **МЕ-Терминал:** Интерактивный GUI-интерфейс для поиска, выгрузки и загрузки ресурсов. Поиск оптимизирован через кастомный клик по бирке в меню.
* **Ячейки памяти (4K, 16K, 64K):** Физические накопители данных. Реализована кастомная сериализация массивов `ItemStack` в **Base64** для хранения внутри `Data Components` предметов.

### 2. Защита от эксплойтов & Нарушения логики
* **Хард-валидация рецептов (`PrepareItemCraftEvent`):** Система блокирует крафт продвинутых ячеек из ванильного мусора. За запуск крафта отвечает строгая проверка уникальных NBT-тегов компонентов. Для создания ячейки высшего тира в центре сетки **обязательно** должна лежать реальная кастомная ячейка предыдущего уровня.
* **Защита от рекурсии данных:** Аппаратно заблокирована возможность положить МЕ-ячейку внутрь другой МЕ-ячейки, что исключает циклическое переполнение памяти и краш чанков.

### 3. Боевая система & Баланс 1.21
* **15-секундный кулдаун на Тотемы:** Внедрен слушатель событий, полностью исключающий спам бессмертием в затяжных PvP-замесах.
* **6 Кастомных PvP/PvE Сетов:** Броня интегрирована под систему `Data Components` (1.21), добавляющая уникальные модификаторы скорости, здоровья и защиты без использования костыльных эффектов зелий. Сеты привязаны к кастомной экономике NPC-торговцев.

### 4. Оптимизация и Стабильность
* **Асинхронный бэкенд БД:** Все тяжелые транзакции по сохранению Base64-строк инвентарей вынесены из основного потока сервера. Это исключает падение TPS и микрофризы при массовых автосейвах данных игроков.
* **Garbage Collector для голограмм:** Автоматический сборщик мусора, отслеживающий и зачищающий забагованные или осиротевшие голограммы в загруженных чанках.

## ⚙️ Требования к среде
* **Ядро:** Paper, Purpur или Fork'и на базе 1.21+
* **Java:** OpenJDK 21 или выше
* **Сборщик:** Maven / Gradle

## 🚀 Деплой и Сборка

1. Клонируй репозиторий:
```bash
git clone [https://github.com/ChetTeam/AstraSMP.git](https://github.com/ChetTeam/AstraSMP.git)
```

2. Собери проект через Maven:
```bash
mvn clean package
```

3. Закинь скомпилированный `.jar` файл из папки `target` в директорию `plugins/` твоего сервера.
