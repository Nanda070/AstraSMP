# 🌌 AstraSMP Core — Огромное Ядро Сервера

![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21-blue?style=for-the-badge&logo=minecraft)

![Language](https://img.shields.io/badge/Language-Java-red?style=for-the-badge&logo=openjdk)
![Status](https://img.shields.io/badge/Status-Alpha--Ready-green?style=for-the-badge)

Высокотехнологичное бэкенд-ядро для сервера **ChetCraft**, написанное на Java под актуальный стек **Minecraft 1.21 (Paper API)**. Плагин заменяет собой целую сборку тяжелых модов (AE2, BloodMagic, RPG-моды и т.д.), реализуя невероятно масштабный и сложный функционал исключительно на стороне сервера.

В этом плагине собрано **всё**: от МЕ-сетей и кровавых ритуалов, до полноценного казино и карманных измерений.

---

## 🛠 Ключевые Системы и Механики

### 🔮 1. Ритуалы, Магия и Оккультизм (`com.astrasmp.rituals`, `pacts`, `blood`, `rift`)
Огромный пласт темных и мистических механик, меняющих геймплей выживания:
* **Ритуальные Круги (`RitualCircleManager`):** Построение многоблочных структур для проведения ритуалов и крафтов.
* **Кровавые Механики (`BloodTankManager`):** Сбор и хранение крови в резервуарах (Blood Tanks) для использования в ритуалах.
* **Ивент Кровавой Луны (`BloodMoonManager`):** Уникальное событие, меняющее поведение мобов и мира.
* **Порча Чанков (`ChunkCorruptionManager`, `CorruptionManager`):** Темные ритуалы и магия постепенно заражают (corrupt) чанки, меняя их свойства и создавая угрозу для игроков.
* **Астрал (`AstralManager`):** Механика выхода из тела (астральной проекции).
* **Разломы (`RiftManager`):** Создание и управление пространственными разломами в мире.
* **Пакты (`PactManager`):** Заключение сделок и пактов (возможно с демонами или другими сущностями), дающих баффы в обмен на дебаффы или ресурсы.
* **Карманные Измерения (`PocketDimensionManager`):** Личные пустотные миры для игроков (с генератором `VoidChunkGenerator`). Вход через команду `/prunus`, выход через `/malus`.

### 💾 2. Цифровые МЕ-Сети (`com.astrasmp.model.MENetwork`, `listener.MEBlockListener`)
Серверная реализация `Applied Energistics 2`:
* **МЕ-Контроллер & Ноды:** Энергетическое ядро сети с ограничением радиуса и узлы подключения.
* **МЕ-Дисковод & GUI:** Блок, вмещающий ячейки памяти. При уничтожении дисковода — ячейки выпадают.
* **МЕ-Терминал:** GUI-интерфейс (`METerminalGui`) для работы с ресурсами. Оптимизированный поиск по предметам.
* **Ячейки памяти (4K, 16K, 64K):** Физические предметы с хранением данных внутри `Data Components` (Base64 сериализация через `ItemSerializer`).
* **Защита от рекурсии:** Защита от NBT-переполнения (нельзя положить МЕ-ячейку в МЕ-ячейку).

### 🎰 3. Полноценное Казино (`com.astrasmp.casino`)
Собственный движок азартных игр внутри Minecraft (с картами и логикой):
* **Блэкджек (`BlackjackGame`):** Карточная игра до 21. Оперирует собственной колодой (`Deck`).
* **Рулетка (`RouletteGame`):** Классическая рулетка со ставками.
* **Слоты / Автоматы (`DrumsGame`):** Вращающиеся барабаны.
* **Классика и Крестики-Нолики (`ClassicGame`, `TicTacToeGame`):** Дополнительные игры для игроков в зоне Казино.

### ⚔️ 4. Хардкорное PvP, Броня и Артефакты (`listener.ArmorMechanicsListener`, `items`)
* **Кастомные PvP/PvE Сеты:** Броня, меняющая скорость, здоровье и защиту через `Data Components` 1.21.
* **Кузница Артефактов (`BlacksmithGui`, `/blacksmith`):** Система крафта и улучшения уникальных предметов с кастомными рецептами (`CustomRecipes`).
* **Абилки предметов (`ItemAbilityListener`):** Предметы с активными навыками и кулдаунами.
* **Кулдаун Тотемов:** 15-секундный кулдаун на использование Тотемов Бессмертия.
* **Дуэли и Арены (`DuelService`, `/arena`):** Система вызова 1х1, арены с точками спавна.
* **Батуты (`TrampolineListener`):** Прыжковые платформы для динамичных сражений.

### 💰 5. Экономика, RPG и Социум
* **Глобальная Экономика (`EconomyService`):** Баланс (`/balance`), переводы (`/pay`), продажа (`/sell`), налоги.
* **Аукционы (`AuctionService`):** Торговля между игроками через GUI.
* **Контракты на убийство (`ContractService`, `/bounty`):** Назначение награды за голову другого игрока.
* **MMR и Таблица Лидеров (`MMRService`, `LeaderboardService`):** Рейтинговая система (Бронза ➔ Элита).
* **Гильдии (`GuildService`, `/guild`):** Создание кланов, управление составом и территориями (ClaimRecord).
* **Семьи (`/marry`, `/unmarry`):** Браки между игроками.
* **Таланты (`TalentsGui`):** Дерево пассивных навыков (`/talents`).
* **Квесты и Награды (`QuestManager`, `RewardsGui`):** Ежедневные квесты и награды за вход.

### 🌐 6. Ивенты, Локации и Discord
* **Ивенты (`EventService`):** Метеорит, Аирдроп, Босс, Сокровища, Галеон, Торговец.
* **Локации (`LocationCommand`, `RegionListener`):** Спавн, Казино, AFK-зона, Ивент-шоп.
* **Интеграция с Discord (`DiscordBridge`, `/link`):** Синхронизация чата, ролей, логов и ивентов с Discord сервером. Автовыдача ролей при связке аккаунта.

### 🛠 7. Администрирование и Оптимизация
* **База Данных (`DatabaseService`, `schema.sql`):** Интеграция с MySQL (HikariCP) для асинхронного сохранения экономики, гильдий, MMR и профилей игроков.
* **Управление (`AdminCommand`):** Выдача предметов, спавн NPC, управление спавном, `/freeze`, `/invsee`, `/vanish`.
* **Управление миром:** Мусоросборщик (Garbage Collector) для голограмм, управление случайной телепортацией (`/rtp`, `/setrtpblock`).
* **Кастомный Tab-лист (`TabService`):** Динамическое оформление таба с префиксами и MMR.

## ⚙️ Технический Стек
* **Ядро:** Paper 1.21+
* **Сборщик:** Gradle (Kotlin DSL `build.gradle.kts`)
* **База данных:** MySQL (схема в `src/main/resources/sql/schema.sql`)
* **Зависимости:** PlaceholderAPI (опционально)

## 🚀 Деплой и Сборка
```bash
git clone https://github.com/ChetTeam/AstraSMP.git
cd AstraSMP
./gradlew clean build  # На Windows: gradlew clean build
```
Готовый `.jar` файл будет лежать в директории `build/libs/`.
